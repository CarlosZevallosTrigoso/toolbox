1. Productividad & Gestión del Tiempo

  • análisis Analiza JSONs exportados de la app de sesión. Calcula métricas de productividad, interrupciones y rachas. Renderiza distribuciones en gráficos de Gantt, sparklines y heatmaps dinámicos sin librerías externas.
  • encadena2 Variante avanzada de agrupamiento con optimización matemática de fricción. Mantiene un historial de encuentros en memoria y permite la edición manual en un lightbox, recalculando colisiones en vivo.
  • encadenados Motor de agrupamiento secuencial preventivo. Utiliza un algoritmo iterativo de 5000 ciclos para mezclar grupos y evitar repeticiones basadas en el historial, operando de forma estrictamente automática.
  • group-maker Generador visual de grupos con 10 algoritmos de asignación, desde Fisher-Yates hasta autómatas celulares y dinámicas físicas con clustering K-Means. Produce un registro exportable para auditar la aleatoriedad.
  • sesión Gestor integral del tiempo de trabajo. Mantiene el estado en localStorage y gestiona temporizadores paramétricos (Pomodoro/Ultradiano). Traza intervalos de tareas anidadas y exporta métricas a JSON/TXT.
  • tabl3 Hoja de cálculo en el navegador con edición fluida sobre atributos contenteditable. Implementa una arquitectura de historial puro mediante clonación de estados y parser propio de CSV (RFC 4180).
  • timer Temporizador visual de precisión. Utiliza un bucle anclado a performance.now() vía requestAnimationFrame para eludir la latencia del navegador. Genera un favicon dinámico con <canvas> para alertas inactivas.
  • timer-multi Temporizador de múltiples rondas personalizables con ejecución secuencial. Mantiene una cola en memoria y avanza automáticamente de fase calculando el progreso visual relativo al bloque activo.
  • timer-multix Temporizador jerárquico que agrupa rondas en fases. Su constructor visual "aplana" el estado en un array lineal que es consumido asíncronamente por el motor de ejecución principal.

2. Imagen, Video & Impresión

  • bnpro Conversor a blanco y negro de grado profesional. Implementa curvas spline para el Sistema de Zonas de Adams, mezcla de canales HSL, Guided Filter para contraste local y simulación de grano sobre ImageData.
  • compositor Editor visual de collages para impresión térmica. Incluye un motor de binarización propio y capacidad para segmentar lienzos verticales largos en múltiples archivos de imagen de salida.
  • contacto Generador de hojas de contacto a partir de video. Captura fotogramas mediante eventos asíncronos en un <video> oculto y lee los primeros bytes del archivo en un DataView para detectar códecs HEVC.
  • image-id Detector de objetos local en tiempo real. Ejecuta ONNX Runtime y Transformers.js descargando modelos ligeros (YOLOS-tiny) para procesar el feed de la webcam, pintando bounding boxes en un canvas.
  • imageforge Conversor y compresor de imágenes por lotes. Detecta soporte de formatos modernos (AVIF, JXL) en el cliente e integra UTIF.js para decodificar archivos TIFF pesados sin pasar por un backend.
  • photocopy-filter Filtro visual que simula texturas de fotocopia o risografía. Aplica pre-desenfoque y umbrales sigmoideos, generando ruido híbrido con Math.random() y Perlin Noise para probabilidad espacial.
  • termica Generador de layouts para impresoras térmicas de rollo continuo a 384px. Mide el texto dinámicamente para el quiebre de línea y aplica conversión a 1-bit mediante umbral estricto o dithering Floyd-Steinberg.
  • video-cutter Editor de video no destructivo en el navegador. Usa ffmpeg.wasm en modo single-thread para copiar streams a nivel de keyframes, o permite recodificación completa con filtros H.264/AAC.
  • video-gif Codificador GIF 100% local. Intercepta eventos seeked en un reproductor de video para capturar fotogramas, aplicando una matriz de dithering de Bayer (4x4) antes de la cuantización de color con gifenc.
  • video-joiner Ensamblador multimedia que utiliza el sistema de archivos virtual de ffmpeg.wasm. Permite la concatenación directa sin pérdida o aplica gráficos de filtros complejos para normalizar resoluciones y framerates.
  • visor Visualizador de corpus en disposición Masonry. Extrae directorios recursivamente, calcula dinámicamente la altura de columnas asimétricas y exporta a PDF inyectando jsPDF para paginar la grilla infinita.

3. Texto, Documentos & Markdown

  • anotador Lector y anotador de Markdown basado en marked.js. Emplea la API nativa CSS.highlights para realizar selecciones visuales no destructivas y calcula offsets sobre el texto plano para exportar notas.
  • ig-text Generador tipográfico para redes sociales. Implementa un algoritmo propio de text-wrap: balance mediante búsqueda binaria de anchos en Canvas y control táctil sobre coordenadas relativas normalizadas.
  • mdviz Visualizador inmersivo de Markdown optimizado para impresión. Sanea el DOM con un TreeWalker para eliminar nodos peligrosos y ajusta el layout dinámicamente mediante variables CSS ajustables.
  • pdf-splitter Fragmentador de documentos PDF pesados. Utiliza pdf-lib.js para cargar el ArrayBuffer, parsear comandos de rangos del usuario y reconstruir asíncronamente nuevos blobs PDF en memoria.
  • pegarmd Ensamblador de archivos Markdown en lote. Intercepta la API Drag & Drop, ordena los objetos File alfabéticamente y concatena sus contenidos forzando la descarga local de un Blob unificado.
  • rizo-lorem Generador paramétrico de corpus textual. Tokeniza oraciones base e implementa cuatro motores de generación, incluyendo shuffle de arrays y cadenas de Markov con profundidad de orden variable.
  • word-counter Contador heurístico avanzado. Extrae texto de DOCX (mammoth.js) y PDF (pdfjs-dist). Si detecta un escaneo por baja densidad, inyecta un Web Worker de tesseract.js para ejecutar OCR local.

4. Criptografía & Esteganografía

  • crypta Suite de cifrado simétrico multiprotocolo. Integra Web Crypto API y tweetnacl.js con derivación PBKDF2. Empaqueta cabeceras binarias y cuenta con un visualizador hexadecimal de difusión de bytes.
  • n0t3.xyz ↗ Bloc de notas criptográfico de extremo a extremo. Cifra el texto directamente en el navegador antes de cualquier transmisión de datos.
  • pixel-msg Encriptador visual esteganográfico. Deriva un keystream de la contraseña y cifra caracteres mapeándolos a píxeles RGB usando la distribución del ángulo áureo en espacios de color HSL.
  • signforge Suite criptográfica para firmas Ed25519. Embebe tweetnacl.js forzando una estricta Política de Seguridad de Contenido (connect-src 'none') para firmar y verificar integridad de archivos offline.
  • stegano Esteganografía LSB con cifrado AES-256-GCM. Su modo adaptativo calcula la varianza de textura para ocultar datos exclusivamente en áreas de alto ruido visual, evadiendo análisis estadísticos.
  • ziplock Compresor ZIP cifrado localmente. Mapea recursivamente carpetas arrastradas mediante webkitGetAsEntry y ensambla el ZIP con cifrado AES-256 en modo STORE directamente en la memoria.

5. Hardware & Sensores

  • captura Agregador de telemetría de hardware. Captura geolocalización, aceleración espacial, audio y frames de video, persistiendo el estado del bloque JSON de manera transaccional en IndexedDB.
  • ojo Cámara "ciega" de captura rápida. Enmascara el feed de video, activa el WakeLock para evitar bloqueos de pantalla e inyecta telemetría GPS directa a la captura guardada en IndexedDB.

6. Desarrollo & Utilidades Web

  • canvas-builder Maquetador visual de posicionamiento absoluto. Permite la edición freeform de elementos del DOM y soporta la exportación a HTML estático auto-contenido o captura a PDF vía jsPDF.
  • ch'ixi Generador de ruido aleatorio determinista (mulberry32). Opera a la resolución nativa física del dispositivo, manipulando directamente arrays de píxeles para generar texturas de alto rendimiento.
  • css-inject Bookmarklet inyector de estilos en vivo. Sobrescribe la paleta tipográfica del sitio anfitrión mediante directivas !important y mantiene persistencia de los ajustes del usuario en localStorage.
  • ig-diff Comparador asimétrico de listas. Utiliza la estructura nativa Set de JavaScript para operaciones de diferencia eficientes O(n), limpiando las entradas mediante regex para exportaciones limpias.
  • qr-gen Interfaz de control estático sobre qrcode.js. Ajusta la resolución del lienzo y el nivel de corrección de errores Reed-Solomon (L, M, Q, H), renderizando el código final para previsualización o PNG.
  • sequenciador Secuenciador MIDI multi-modo. Utiliza Tone.js para la síntesis de instrumentos y patrones algorítmicos. Exporta el arreglo completo a WAV/MP3 renderizando buffers en un OfflineAudioContext.
