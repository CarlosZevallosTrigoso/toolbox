¿Qué es esto?

Este verificador comprueba firmas digitales Ed25519. Si un contenido fue firmado con la clave privada correspondiente a la clave pública del autor, la verificación lo confirma matemáticamente. Si un solo carácter fue alterado, la verificación falla.

¿Cómo verifico?

Sube el archivo firmado o pega su contenido en el campo de verificación. La herramienta separa automáticamente el contenido del bloque de firma <!-- SIG:ED25519 ... --> y verifica la autenticidad. La clave pública se extrae del bloque o se usa la del banner.

¿Cómo sé que la clave pública es auténtica?

Contrasta la clave con la publicada en múltiples fuentes independientes del autor: su sitio web, GitHub, perfil institucional. La convergencia de fuentes establece confianza.

¿Es seguro?

Todo corre en tu navegador. La política de seguridad de esta página (connect-src 'none') bloquea cualquier conexión saliente, lo que impide que cualquier código — incluso malicioso — envíe datos fuera de tu navegador. No hay scripts externos: la librería criptográfica está embebida directamente en el HTML. El algoritmo Ed25519 es el estándar usado por SSH, Signal, Tor y WireGuard.

Verificación independiente

La firma no depende de esta herramienta. Cualquier implementación de Ed25519 puede verificarla. Extrae del bloque la firma y la clave pública (ambas en base64), y el contenido firmado es todo lo que está fuera del bloque.

Python

import base64
from nacl.signing import VerifyKey

pubkey = base64.b64decode("TU_CLAVE_PUBLICA_BASE64")
signature = base64.b64decode("LA_FIRMA_BASE64")
content = open("archivo.html").read()

# quitar el bloque de firma del contenido
import re
content = re.sub(r'\n<!-- SIG:ED25519[\s\S]*?-->', '', content)

verify_key = VerifyKey(pubkey)
verify_key.verify(content.encode(), signature)
print("Firma válida")

Node.js

const nacl = require('tweetnacl');
const fs = require('fs');

const pubkey = Buffer.from("TU_CLAVE_PUBLICA_BASE64", 'base64');
const signature = Buffer.from("LA_FIRMA_BASE64", 'base64');
let content = fs.readFileSync("archivo.html", "utf8");

// quitar el bloque de firma del contenido
content = content.replace(/\n<!-- SIG:ED25519[\s\S]*?-->/, '');

const ok = nacl.sign.detached.verify(
  new TextEncoder().encode(content), signature, pubkey
);
console.log(ok ? "Firma válida" : "Firma inválida");
