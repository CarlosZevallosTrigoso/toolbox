YOLOS-tiny

Adapta la arquitectura ViT (Vision Transformer) para detección de objetos. Más liviano (~25MB ONNX), buena relación velocidad/precisión. Ideal para demos interactivas.

DETR ResNet-50

Transformer end-to-end de Meta. Backbone ResNet-50 con encoder-decoder. Más pesado (~160MB) pero significativamente más preciso en escenas complejas.

Arquitectura

Usa Transformers.js con ONNX Runtime. Los modelos se descargan una vez y se cachean en el navegador. Toda la inferencia es local.

Deploy

Un solo archivo HTML, cero backend. Compatible con GitHub Pages, Netlify, o cualquier hosting estático. Modelos servidos desde Hugging Face CDN.
