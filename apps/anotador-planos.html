      anotador-planos

      VSeleccionar / mover. Arrastrar el fondo desplaza la vista; rueda = zoom.
      MMarcador numerado. Puede llevar nota y enlace.
      TTexto sobre el plano (escala con el zoom).
      IImagen incrustada; clic para situarla.
      DCota: dos clics. Muestra la longitud real si hay calibración.
      PPolígono: clics, doble clic o Enter para cerrar. Muestra el área.
      ZZona rectangular: arrastrar. Muestra el área.
      XMedir sin crear anotación.
      CCalibrar: dos clics sobre una longitud conocida y escribe los metros.
      SuprBorrar seleccionado. Esc cancela. Ctrl+Z/Y deshacer/rehacer. 0 ajustar vista. +/− zoom.

      Guardar produce un .json con todo (imágenes incluidas). Exportar HTML produce este mismo archivo en modo lectura, con el proyecto incrustado y los enlaces activos; desde ahí «Editar» vuelve a abrir el editor. El trabajo se guarda solo en este navegador (localStorage) mientras quepa.
